▸ Getting started & help
What this is
A bench tool for developing and testing Subaru 5EAT TCU firmware. It runs a physics-based car simulator that drives the transmission logic, and a live window into a real TCU's internal memory over SSM. Everything works with no hardware (demo / mock), and lights up when you connect the bench.
Demo vs hardware
With no CANtact connected it runs an internal transmission model so the UI is fully drivable. Plug in a CANtact Pro and a powered TCU on the bench and it drives the real bus and reads the TCU's broadcasts.
Drive it
Pick a firmware ROM and power level, then drive: throttle/brake sliders, the P-R-N-D-M selector, or the keyboard (W throttle, S brake, P R N D M range, [ ] manual gear). Or run a scripted test drive / duration run and let it log.
Live TCU memory
The Live TCU memory panel reads the firmware-mapped RAM off a real TCU over SSM (Tactrix OpenPort 2.0 on K-line), or a mock TCU fed by the simulator. The ✎ button writes a byte (live poke) — use with care on a real unit.
Firmware ROMs
The full TCU ROM set (25 firmwares, both families) is supplied and populates the selector automatically. To use a different set, point TCUSIM_ROM_DIR at your own folder of .bin files.
Logging (AI-ready)
Runs and the live monitor write JSONL logs with full CAN/telemetry capture, for automated analysis. See the Data logging and Live panels. Close the app with the ⏻ Quit button in the header.

Car → TCU frames (the simulated bus) and the TCU's own broadcast. In demo the TCU frames are synthesized; with a CANtact + TCU on the bench these are the real frames off the wire.

Live TCU memory disconnected

Reads the firmware-mapped RAM off a real TCU over SSM (Tactrix OpenPort 2.0 on K-line), or a mock TCU fed by the simulator when no cable is present. Values are decoded from the 8AF0237300 firmware trace. Writes are live pokes (SSM 0xB8) — use with care on a real unit.

Data logging — AI-ready

Runs the selected scenario/duration faster-than-real-time and writes a JSONL log with the full CAN capture (RX + TX frames), telemetry, shift events and summary — for the current firmware + power. Machine-readable for automated firmware analysis.

Self-test

Runs the full test suite — CAN byte-correctness, all ROMs, determinism, log integrity, edge cases, physics bounds across every power level.
